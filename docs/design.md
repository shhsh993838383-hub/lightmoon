# 光幕 UI 设计决策

设计判断：面向自由组合标签、慢慢探索电影的人，采用电影资料馆式内容浏览界面。属于消费内容产品，不是后台仪表盘；应用 taste-skill 中适用的排版、色彩、图片、交互与验证规则。

目前目录没有既有前端、品牌、网址或导航约束，为新建项目。保留已确认的自由标签探索方向。名称由用户确认为“光幕”，英文名由用户确认为“lightmoon”。

- DESIGN_VARIANCE: 6。页面采用侧栏与海报墙，配一个比例错落的片单入口；主体保持易浏览的规则网格。
- MOTION_INTENSITY: 3。只用 hover、按下、焦点与状态反馈，减少浏览干扰。不引入持续动画库。
- VISUAL_DENSITY: 5。让首屏能够看见海报，筛选常驻，进阶选项折叠。
- 基础：React、Vite、Tailwind v4，原生语义控件与 CSS 设计变量；不冒充某个官方设计系统。图标统一使用 Phosphor regular/bold 两种功能性字重。
- 字体：使用本机中文无衬线系统字体，避免外部字体请求；标题不混用衬线字体。
- 色彩：石墨灰与银白作为双主题基础，同一个珊瑚色系为强调色。两种模式分别校准对比度。
- 圆角规则：海报与输入框 8px；大版块与弹窗 16px；标签和小按钮 6px；主题快捷入口 999px。
- 层级：内容 0、页头 20、移动筛选遮罩 40、详情弹窗 60、轻提示 80。
- 图像：真实电影使用对应发行海报，不用生成图或风景照片代替海报。来源和影片标识随数据保存。
- 适配：桌面侧栏常驻；1024px 以下简化导航；768px 以下筛选为可关闭抽屉，海报两列，精选版块收紧。
- 状态：图片加载与失败、空筛选、空想看片单、详情、收藏、筛选恢复、主题切换、手机筛选抽屉。
- 数据诚实：当前只有示例片库，显示真实本地条数；不虚构全球影片数量、用户数、评分或播放渠道。

海报、已知影片资料与本地人工观感标签是不同来源。主观标签用于体验验证，不标成全球数据库的权威结论。
